# Prominence II updates

Mods added on top of the base Prominence II v4.1.2 instance. Friends' Prism instances sync from this pack before launch.

- `add-mod.bat`: add a mod by Modrinth or CurseForge URL and publish it.
- `remove-mod.bat`: remove a mod added here and publish it. It cannot remove mods from the base instance.
- `update-server.bat`: sync the server (stop the server first).

If a launch fails with "excluded from the CurseForge API", that mod cannot be auto-downloaded: remove it, or use its Modrinth version.
